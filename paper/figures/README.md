# Manuscript Figures

This directory contains figures for the research manuscript.

## Figure Files

- `accuracy_vs_latency_tradeoff.png` - Performance vs. computational latency across configurations (E1-E4)
- `category_performance_breakdown.png` - Accuracy breakdown by evidence condition
- `ablation_impact_analysis.png` - Component ablation impact on overall accuracy

## Figure Generation

Figures are generated by the exploratory analysis notebook:
```bash
jupyter notebook notebooks/exploratory_analysis.ipynb
```

## Figure Specifications

- Format: PNG
- DPI: 300
- Font: DejaVu Sans / Arial
- Style: seaborn-v0_8-whitegrid
